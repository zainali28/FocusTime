# ⏳ FocusTime  

A **React Native** productivity app designed to help users focus by using the Pomodoro technique. Built with **React Native, Expo, and Context API**, this app allows users to break tasks into focused work sessions with short breaks.  

## 🚀 Features  
✅ **Pomodoro Timer** – Work in timed sessions with breaks.  
✅ **Task Management** – Add and track tasks to focus on.  
✅ **Customizable Timers** – Set your preferred work and break durations.  
✅ **Minimal & Distraction-Free UI** – Stay focused on your tasks.  
✅ **Smooth UI & Performance** – Optimized for fast, responsive navigation.  

## 🛠️ Tech Stack  
- **Frontend**: React Native, Expo  
- **State Management**: React Context API  

## 📦 Installation  
1. Clone the repository:  
   ```bash  
   git clone https://github.com/zainali28/FocusTime.git  
   cd FocusTime  
   ```  
2. Install dependencies:  
   ```bash  
   npm install  
   ```  
3. Start the app:  
   ```bash  
   npm run start  
   ```
